# Notebook Plan

This folder is intentionally lightweight so the project remains reproducible from scripts.

Recommended notebooks:

1. `01_data_understanding.ipynb`
   - Load `data/raw/matches.csv` and `data/raw/deliveries.csv`.
   - Validate columns, missing values, innings distribution, and winner coverage.
   - Inspect team-name changes such as Delhi Daredevils to Delhi Capitals.

2. `02_eda_feature_engineering.ipynb`
   - Call `build_second_innings_features`.
   - Plot class balance, required run rate trends, wickets remaining, and pressure index.
   - Explain why each engineered feature should affect chase probability.

3. `03_model_evaluation_explainability.ipynb`
   - Compare the saved metrics in `artifacts/metrics.csv`.
   - Inspect `artifacts/feature_importance.csv`.
   - Display the SHAP summary generated by `scripts/train.py`.

The production path is script-first:

```bash
python scripts/run_eda.py
python scripts/train.py
python app.py
```
